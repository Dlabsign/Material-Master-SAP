🎯 Apa Fungsi Halaman Ini?

Halaman ini digunakan oleh unit kerja / user untuk mengajukan pembuatan atau pengkinian Master Data Material SAP S/4HANA secara mandiri, terstruktur, dan aman sebelum data diposting resmi ke sistem SAP.

Fungsi Utama Yang Tersedia:
Upload File Excel

Unggah banyak item material sekaligus menggunakan template Excel resmi tanpa perlu input manual satu per satu.

Input Multi-Item (+ Add Line)

Tambah dan edit baris material langsung di tabel browser lengkap dengan validasi tipe data real-time.

Asisten AI Validation

Fitur cerdas untuk cek keunikan deskripsi material dan rekomendasi klasifikasi otomatis.

Attachments & Timeline

Lampirkan dokumen spesifikasi teknis / PDF dan pantau status persetujuan secara transparan.

Berkas & Format Template Excel

Untuk mengunggah data dalam jumlah banyak, wajib menggunakan Format Excel Standar Existing yang tersedia di sistem agar kolom terpetakan dengan tepat.

Template Excel Resmi: data_material.xlsx
Berisi struktur kolom MARA, MARC, MVKE, MBEW, dan MAKT.
Download Template
Kolom Wajib Isi (Mandatory Fields):
  • MAKTX Deskripsi Material (Maksimal 40 karakter, huruf kapital).
  • MTART Material Type (Contoh: ZRAW, ZFIN, ZSPM, FERT).
  • WERKS Plant / Pabrik tempat material digunakan (Contoh: 1101).
  • LGORT Storage Location / Gudang penerima (Contoh: 1001).
  • MEINS Base Unit of Measure (Satuan Dasar, Contoh: PC, KG, M).
  • BKLAS Valuation Class (Klasifikasi Akuntansi SAP, Contoh: 3000).

Alur Kerja Pengajuan (Workflow Flowchart)

1. Create Request
→
2. Data Steward
→
3. Approved Pak Sur
→
4. Master Data SAP
1. Tahap Create Request (Requester)

User mengunggah data material atau mengisi form online, melengkapi dokumen penunjang, lalu menekan tombol Submit Request. Status data berubah menjadi SUBMITTED.

2. Tahap Data Steward (Verifikasi & Pengecekan)

Data Steward meneliti kelayakan data, duplikasi nama, serta standar penamaan SAP. Status data berubah menjadi CHECKED.

3. Tahap Decision Maker (Approval Pak Sur)

Pihak wewenang (Pak Sur / Approver Master Data) menyetujui pengajuan. Jika disetujui, status menjadi APPROVED.

4. Integration ke Master Data SAP S/4HANA

Sistem secara otomatis memposting data ke SAP S/4HANA dan menerbitkan Kode Material SAP resmi yang dapat digunakan untuk transaksi purchasing/inventory.

Bagaimana Cara File Diproses Sampai Di-Approve?

Proses persetujuan dijalankan secara bertahap melalui sistem staging tanpa perlu pengiriman fisik dokumen.

  1. Validasi Automatis Sistem: Saat user mengunggah file, sistem melakukan pengecekan format cell, tipe data, dan keunikan deskripsi awal.
  2. Notifikasi Outbound Email SAP: Begitu request dikirim (SUBMITTED), sistem meregistrasikan notifikasi email di queue SAP SOST kepada Data Steward & Approver.
  3. Review & Keputusan Approver: Data Steward / Pak Sur dapat melakukan Approve, Hold (apabila butuh revisi data), atau Reject (disertai alasan penolakan).

🏷️ Menampilkan Kode Material Hasil Approval

Setelah pengajuan disetujui, sistem menerbitkan nomor kode material SAP resmi untuk seluruh item dalam request tersebut.

Di mana Saya Bisa Melihat Kode Material?

Anda dapat melihat seluruh kode material yang dihasilkan melalui 2 cara mudah:

  • 1 Klik tombol "Lacak" pada tabel Riwayat Pengajuan untuk membuka modal timeline tracking.
  • 2 Lihat pada Tahap 3: Keputusan Akhir & Master Data SAP. Seluruh kode material yang berhasil diproduksi (misal 5 item) akan ditampilkan dalam bentuk badge hijau yang jelas dan mudah disalin (copy).
